## 🇬🇧 English

This repository contains my personal solutions to the problem sets, labs, and projects completed for Harvard University's **CS50x: Introduction to Computer Science**.

I successfully completed the course and earned my verified certificate.

### ⚠️ Academic Honesty Notice

All code in this repository is my own original work, shared here for portfolio and educational purposes after completing the course.

If you are currently enrolled in CS50, please do not copy this code as your own submission. Doing so would violate CS50's Academic Honesty Policy. Try to solve the problems yourself first — that's where the real learning happens.
